# Decision records

This is the router for living records that preserve important product or architecture intent.
Records are grouped by capability and stable concern so agents can read the smallest relevant set.

- [Pi local search](agent-tooling/pi-local-search.md) — Local CodeGraph and SearXNG tools, with separate service and Pi MCP ownership.
- [Delegation routing](agent-tooling/delegation-routing.md) — Runtime-aware harness selection, central role/model/thinking defaults, and local-model concurrency.
- [Post-implementation quality gates](agent-tooling/post-implementation-quality-gates.md) — Read-only deslop audits and opt-in OCR/Slopo evidence.
- [Git workflow](agent-tooling/git-workflow.md) — One `git` skill for commit, push, PR, merge, and PR-comment triage, with repository conventions over shared defaults.
- [Writing](agent-tooling/writing.md) — One `writing` skill owning the merged slop rules, the voice profile, and opt-in academic and LaTeX references.
- [Agentic workflow](agent-tooling/agentic-workflow.md) — Human-gated planning and delivery, sequential stacked slices, local progress, and separate implementation/project decisions.
- [Project initialization](agent-tooling/project-init.md) — One `init` command that sets up or repairs a repository for agents, with `AGENTS.md` followed by every harness.
- [Harness portability](agent-tooling/harness-portability.md) — One shared configuration source and installer, with four native bootstraps and preserved local state.
